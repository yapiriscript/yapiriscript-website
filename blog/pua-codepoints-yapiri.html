How PUA Codepoints Work and Why Yapiri Uses Them

Every custom script needs a home in the digital world. Discover what the Unicode Private Use Area is, exactly which addresses Yapiri occupies, and the road ahead toward official encoding.

Creating a new script is only half the challenge. The real question is: how do you make it work on computers, phones, and the internet? Every character on every device has a number. That number — a codepoint — is what tells software which shape to draw. Without a codepoint, a character cannot be typed, stored, searched, or shared.

For Yapiri, solving that problem required understanding a quiet but powerful corner of the Unicode standard called the Private Use Area.

What Unicode Is and Why It Matters

Unicode is the universal standard that assigns a unique number to every character that computers need to represent — from English letters and Bengali digits to ancient cuneiform, modern emojis, and mathematical symbols. The standard currently covers over 149,000 characters across hundreds of scripts and symbol sets.

When you type a letter and it appears on screen, what is actually being stored is that letter's codepoint: a number. The font then reads that number and draws the corresponding shape. If the number has no official Unicode assignment — because the script is newly created and has not yet been submitted for encoding — a font cannot know which shape to draw by any agreed convention.

This is exactly the situation Yapiri found itself in: a complete, 49-character writing system with no official Unicode block. The solution the standard itself provides for exactly this situation is the Private Use Area.

The Private Use Area

The Unicode Standard deliberately reserves a range of codepoints and declines to assign any official meaning to them. This range — called the Private Use Area, or PUA — runs from U+E000 to U+F8FF in the Basic Multilingual Plane (6,400 codepoints). There are two additional PUA blocks in the supplementary planes, giving a total of 137,468 private-use slots.

The standard's promise is simple: these codepoints will never be given an official meaning by Unicode itself. They are blank by design, available for private agreements between font developers, applications, and communities. Think of them as reserved plots on a map — the city has built roads to them but committed never to build anything there, so others can use the land as they see fit.

Key Point A PUA codepoint is not the same as an unassigned codepoint. Unassigned codepoints may eventually receive official characters. PUA codepoints are permanently reserved for private use and will never be officially assigned.

Yapiri's Exact Codepoint Range

All 49 Yapiri characters are encoded in the BMP Private Use Area. The assignment is compact and sequential, starting at U+E000 — 48 primary characters plus one additional character — the hyphen (U+E02E), used between reduplicated words.

This gives Yapiri a clean, 49-slot footprint in the PUA. Because the assignment is sequential, it is easy to verify, easy to document for developers, and easy to migrate if official Unicode encoding is ever achieved in the future.

Why PUA Was the Right Choice

When designing Yapiri's encoding, there were really two options:

  • Wait for official Unicode encoding — a process that typically takes several years, requires substantial documentation, demonstrated community use, and surviving multiple review cycles.
  • Use PUA codepoints immediately, allowing the font, the keyboard, and the web tools to be released while that longer work proceeds in parallel.

The second path was the only practical one.

"A script that cannot be typed today cannot preserve a language tomorrow."

— Design philosophy of Yapiri

PUA encoding is not a workaround or a shortcut. It is the standard's intended mechanism for exactly this use case. Many well-known private scripts — including Klingon, Tolkien's scripts, and numerous indigenous writing systems — have lived entirely in the PUA for decades, serving their communities reliably. It is a legitimate, well-understood home.

The Limitation: Font Lock

PUA encoding does come with one real constraint: the text is font-locked. A PUA codepoint has no universal meaning — only the Yapiri font knows that U+E008 should be drawn as the consonant /k/. Any other font will either draw nothing, display a placeholder box, or — worse — draw a completely different character if that font also uses the same PUA slot for its own purposes.

This means Yapiri text can only be read on a device where the Yapiri font is installed or loaded. It works perfectly on yapiriscript.com (where the font is loaded from the web), and it works on any device where the user has installed Yapiri.ttf. Outside those contexts, the text becomes unreadable to the eye, even though the underlying codepoints are still there and correctly stored.

Practical If you paste Yapiri text into a platform that does not have the font, you will see boxes or blank spaces. The characters are not lost — they are just invisible without the font. Install the font on the destination device, or share the text via yapiriscript.com where it will render correctly.

The Road Ahead: From PUA to Official Encoding

PUA is a bridge, not a permanent home. The long-term goal is to submit Yapiri for official encoding in the Unicode Standard, which would assign it a permanent, globally recognised block — the way Chakma (another script used in the region) received its own block at U+11100.

The prerequisites for that submission are already in progress: the character database is complete, a canonical set of codepoints is documented for all 49 characters, and a transcoder exists that can migrate all existing Yapiri text to a future official block by changing a single constant. When the day comes, no text written in Yapiri today will need to be retyped or reformatted.

 kokborok — U+E008 U+E004 U+E008 U+E00C U+E004 U+E017 U+E004 U+E008 Eight glyphs. Eight codepoints. One word. Wherever the font goes, the text follows.

The Heart of the Matter

Using PUA codepoints was a practical, well-reasoned choice. It reflects a belief that our language should not have to wait for permission to exist in the digital world. Yapiri exists and can be typed today — fully, correctly, and portably within any environment where the font is present — because we chose action over waiting.

Every time you type in Yapiri, the codepoints that carry your words are quietly sitting in a corner of the Unicode standard that was designed for exactly this purpose. The glyphs may live in private addresses for now, but the language they carry is very public: Kokborok, written beautifully and proudly by its people.
